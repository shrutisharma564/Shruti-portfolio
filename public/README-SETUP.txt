Shruti Sharma — Portfolio Setup
================================

1. Run: npm install
2. Run: npm run dev
3. Open the local URL shown by Vite.

Before deploying:
- Add your resume PDF at public/resume.pdf (the Hero and Navbar
  "Resume" buttons link directly to /resume.pdf).
- All social/profile links (GitHub, LinkedIn, LeetCode, GFG) and
  project repo links are already set in src/data/site.js and
  src/data/projects.js — update them there if anything changes.

Build & deploy:
4. Run npm run build before deployment.
5. Deploy the project on Vercel or another static hosting service.
